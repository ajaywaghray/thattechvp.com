# thattechvp.com

Source for [thattechvp.com](https://thattechvp.com), the Tech VP site.

It's a single static page (`index.html`, `style.css`, `tech-vp.jpg`) hosted on
GitHub Pages, served directly from the root of the `main` branch. There is no
build step: edit the files and push to `main` to publish.

- `CNAME` sets the custom domain for GitHub Pages.
- `.nojekyll` tells Pages to serve the files as-is, without Jekyll processing.
